# Objectives

Deliver a first-party, privacy-first, offline Android keyboard with a
genuine Android input-method service, native Compose interfaces, and
direct adoption of the canonical GoreeCloud UI Material 3 Expressive source.
The keyboard must not transmit keystrokes or require an account.

Acceptance gates include correct Android IME registration, editing across
common editor types, sensitive-field behavior, accessibility, representative
physical Android-device evaluation, reproducible CI builds, a vetted license
inventory, and controlled release/signing. Design approval and Stable release
are not established by the repository's existence or a desktop build.
