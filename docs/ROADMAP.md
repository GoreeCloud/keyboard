# Roadmap

1. **Foundation**: establish a real Android IME, in-repo GoreeCloud UI
   adapter, a license inventory, CI, unit tests and local debug build.
2. **Typing quality**: editor compatibility matrix, composing text,
   dead keys / accents, language selection, candidate ranking and
   autocorrect; tests with privacy boundaries and sensitive fields.
3. **Input modes**: gesture typing, emoji/GIF/stickers, on-device speech
   and handwriting after licensing/model/runtime feasibility review.
4. **Acceptance**: physical device + TalkBack, performance/latency,
   secure release signing, regression suite and founder visual approval.
5. **Integration**: optional, consent-based GoreeCloud Mesh interfaces,
   with GoreeShield/Wardveil/Identity constraints and offline independence.

Roadmap items are proposals, not claims of delivered features or release dates.
